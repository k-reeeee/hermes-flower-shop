three.js, low-poly flat-shaded floating garden island; hemisphere + warm key + soft PCF shadows + ACES. Static scenery baked to shared vertex-colour materials (~140 draw calls desktop / ~85 phone). Canvas2D fallback when WebGL is unavailable. Bouquet = live order; selected = rose ring + beacon; late = red ring + beacon.
